# Замер скорости скачивания

`speed_test.py` делает 10 последовательных GET-запросов к одному URL. Каждый следующий запрос начинается после того, как скрипт прочитал весь предыдущий ответ. Тело ответа читается блоками и подсчитывается без сохранения файла.

## Запуск

Нужен Python 3.10 или новее. Скрипт использует стандартную библиотеку.

```sh
python speed_test.py "https://example.com/"
```

Для замера подставьте прямую HTTP- или HTTPS-ссылку на большой файл, например изображение. Скрипт скачает его 10 раз. При HTTP-ошибке, перенаправлении или обрыве ответа скрипт выводит номер проблемного запроса и завершает работу с кодом `1`. Тайм-аут одной блокирующей сетевой операции составляет 30 секунд.

## Результаты

- **Среднее время запроса, мс** — среднее время от начала запроса до чтения всего тела ответа.
- **Объём, байт** — сумма размеров тел всех 10 ответов.
- **Скорость, Мбит/с** — общий объём в битах, делённый на суммарное время запросов в секундах и на 1 000 000. Один байт равен 8 битам.

Скорость включает время установки соединения и ожидания ответа. На результат влияют выбранный сервер, размер ответа и состояние сети.
